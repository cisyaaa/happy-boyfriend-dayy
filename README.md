# Happy Boyfriend Day 💙

Website gift sederhana yang bisa dipublikasikan dengan GitHub Pages.

## Cara mengedit
Buka `index.html`, lalu cari bagian `EDIT BAGIAN INI`.
Ganti `Nama Dia` dan isi surat sesuai keinginan.

Untuk menambahkan foto, kamu bisa mengganti bagian `photo-placeholder` dengan gambar sendiri.
